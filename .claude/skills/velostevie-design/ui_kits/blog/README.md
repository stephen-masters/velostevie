# Vélostevie — Blog UI Kit

High-fidelity React recreation of the Vélostevie blog. Uses inline JSX + Babel so you can open `index.html` directly.

## Screens (click-thru)
- **Home** — hero + recent route reports + tag strip
- **Route report** — editorial article layout with embedded map, stat block, GPX download, photo gallery
- **Route index** — filterable grid of all routes
- **World map** — all routes pinned on one map
- **Gallery** — photo-forward grid

## Components
- `Nav.jsx`, `Footer.jsx`, `Logo.jsx`
- `RouteCard.jsx`, `StatBlock.jsx`, `Eyebrow.jsx`, `PullQuote.jsx`
- `MapEmbed.jsx` (faked map canvas with route lines + pins)
- `PhotoGrid.jsx`, `Placeholder.jsx`
- `Button.jsx`, `TagPill.jsx`, `Input.jsx`
